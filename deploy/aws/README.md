# AWS Lightsail production deployment

The production LMS runs on a single Amazon Lightsail instance so the database,
Redis, workers, websocket server, proxy, and application storage stay together.
This is less expensive than an equivalent EC2 instance after EC2 public IPv4
and EBS charges are included.

## Current resources

- Region: `ap-south-1` (Mumbai)
- Instance: `dsacademy-lms-prod`
- Bundle: `small_3_1` (2 vCPU, 2 GB RAM, 60 GB SSD)
- Static IP: `dsacademy-lms-ip`
- Public hostname: `learn.dsacademy.lk`
- Container: `ghcr.io/nizarhaider/dsacademy-lms:stable`
- Monthly budget: `DS-Academy-LMS-monthly` at USD 13

The instance bundle is USD 12 per month, billed hourly up to the monthly
maximum. It includes the SSD, public IPv4 address, and transfer allowance. No
managed database, load balancer, NAT gateway, or additional volume is used.

Netlify DNS owns the `dsacademy.lk` zone. Its `learn` A record points to the
Lightsail static IP. Traefik obtains and renews the Let's Encrypt certificate.

## Runtime

The host uses the production Compose file generated by Frappe's installer:

```bash
docker compose --project-name dsacademy_lms \
  --file ~/dsacademy_lms-compose.yml ps
```

The host has a 4 GB swap file with `vm.swappiness=10`. This provides a startup
safety margin without replacing the 2 GB RAM requirement.

The Frappe scheduler is enabled for background jobs and scheduled backups.

## Deploy an update

```bash
cd ~/dsacademy-lms
git pull --ff-only
docker pull ghcr.io/nizarhaider/dsacademy-lms:stable
docker compose --project-name dsacademy_lms \
  --file ~/dsacademy_lms-compose.yml up --detach
docker compose --project-name dsacademy_lms \
  --file ~/dsacademy_lms-compose.yml exec backend \
  bench --site learn.dsacademy.lk migrate
docker compose --project-name dsacademy_lms \
  --file ~/dsacademy_lms-compose.yml exec backend \
  bench --site learn.dsacademy.lk execute lms.dsacademy.seed.seed_all
```

Pull the application image once before starting Compose. The same image is used
by several services, and pre-pulling prevents redundant concurrent extraction
on this small host.

## Verify

From a checkout of this repository:

```bash
bash deploy/oci/verify.sh
```

The verifier checks the public API, LMS pages, course image, English audio, and
English video.

## Backup

The live host runs `deploy/aws/backup-to-s3.sh` daily. It creates a compressed
Frappe database and file backup, then syncs the backup directory to a private,
encrypted S3 bucket through a bucket-scoped IAM user. S3 lifecycle rules delete
objects after 30 days.

Run an off-instance backup manually:

```bash
S3_BUCKET=dsacademy-lms-backups-744861799976-ap-south-1 \
  bash ~/dsacademy-lms/deploy/aws/backup-to-s3.sh
```

Create only a local backup:

```bash
docker compose --project-name dsacademy_lms \
  --file ~/dsacademy_lms-compose.yml exec backend \
  bench --site learn.dsacademy.lk backup --with-files
```

Copy verified backups off the instance. Deleting the instance also deletes its
local storage.

## Cost controls

AWS Budgets emails at 80% forecast and 100% actual usage of the USD 13 monthly
limit. Check the remaining Free Tier credit balance with:

```bash
aws freetier get-account-plan-state
```

The AWS account is a paid plan. Once promotional credits are exhausted, the
Lightsail bundle becomes a normal recurring charge.
